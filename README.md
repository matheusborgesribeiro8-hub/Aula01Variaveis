## 📘 Guia de Formatação Markdown

Este arquivo utiliza a linguagem **Markdown**. Aqui está um resumo rápido de como formatar seus textos:

### 1. Títulos
Use `#` para títulos:
- `# Título Principal`
- `## Título Secundário`
- `### Título de Seção`

### 2. Estilos de Texto
- **Negrito**: `**texto**`
- *Itálico*: `*texto*`
- ~~Tachado~~: `~~texto~~`
- `Código em linha`: `` `código` ``

### 3. Listas
- **Não ordenadas**:
  - `* Item 1`
  - `* Item 2`
- **Ordenadas**:
  1. `1. Primeiro`
  2. `2. Segundo`

### 4. Links e Imagens
- **Link**: `[Texto do Link](https://google.com)`
- **Imagem**: `![Texto alternativo](url-da-imagem.jpg)`
